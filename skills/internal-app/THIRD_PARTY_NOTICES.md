# Third-Party Notices

## ReUI

The kit files below use the behavior, the API shape, and the visual design of
free components from ReUI (https://reui.io, https://github.com/keenthemes/reui).
The kit re-implements them with StyleX, react-aria-components, and lucide. It
does not include ReUI source code, Tailwind classes, or Base UI or Radix
primitives. Only the free, MIT-licensed ReUI components and examples were
used. No ReUI Pro block or template was used.

Each file has a one-line header that points to this notice.
