# Dashboards And Data

Organize data by user task, not by database fields.

## Overview

- Put overview values where users can read them at a glance.
- Let labels support values. Labels must not compete with values.
- Use recent or important records for a rich summary. Add a denser table for deeper inspection only when the two views serve different tasks.
- To show several facts on one line, use [[grouped-values]].

## Values That Reduce Work

- Convert raw values into forms that reduce mental work. An example is a relative or human-readable date when the exact date is not necessary.
- Consolidate secondary fields when users do not sort or scan them independently.
- Keep identifiers, important values, and high-severity states visible when space is limited.

## Status

- Use color to enrich status, not to carry status alone. Pair it with text, an icon, or a shape.
- Prefer dark text on a soft status background when a saturated badge would overpower the page.
- In a dark theme, use the status color for text or an icon and its soft color for the surface. [[graphite#usage-rules]] gives the pairs.
