# Form Choices

Show a small closed set of choices on the page. A dropdown hides the options and costs two actions. Use a dropdown only for a long list, or in a row that has no space.

## Chips

- For one choice from about seven or fewer short labels, use radio chips.
- For several choices, use checkbox chips that show a check when selected.
- Add a quiet fact to a chip when it helps the choice, such as the open work of each person.

## Cards

- When users compare the options, use cards with one sentence that states the difference. An example is the response time of each priority.
- Use richer option cards only when the choices contain meaningful values that users must compare.
- In a choice card, emphasize the differentiator and reduce repeated labels.
- Show selection with more than color. [[accessibility#color-is-never-the-only-signal]] gives the rule.

## No Value

Give an optional single choice an explicit "no value" option, such as "Decide later". Users do not discover that a second press clears a selected chip.

## Dates

For a date that is usually in the next few days, show those days as chips. Keep a date input for any other day.
